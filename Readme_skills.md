# Памятка по добавленным скиллам

Как вызывать: назовите скилл по имени в запросе, например «Сделай калькулятор, используй design-wise-calculator-forms». Можно указать два скилла: один задаёт стиль, другой качество и проверку.

## 1. Дизайн-стили для вашего проекта (B2B, металлоконструкции, внутренние сервисы)

Это сжатые выжимки из DESIGN.md известных сайтов: палитра, шрифты, правила и запреты. Они задают стиль, но готовых макетов не дают. Шрифты брендов частные, поэтому нужно использовать запасные (Inter, IBM Plex Sans, Geist и т. п.).

## 2. Общие инструменты

| Скилл | Для чего | Ограничение |
|---|---|---|
| design-taste-frontend-v1 | Общие правила «дорогого» фронтенда на React/Next.js, Tailwind и Framer Motion: запреты на типовые приметы ИИ-дизайна, настройки насыщенности и движения | Это оригинальная v1; правила жёсткие и стилистически самостоятельные, поэтому не смешивайте её с брендовыми скиллами из раздела 1 |
| impeccable | Редизайн и аудит интерфейса: критика, полировка, типографика, цвет, движение, UX-тексты | Сохранён только основной файл. Вызовы `scripts/impeccable` и ссылки на `reference/` не работают, поэтому детальных инструкций по подкомандам нет |
| playwright-cli | Управление браузером из командной строки: открыть страницу, кликнуть, заполнить форму, сделать скриншот, проверить вёрстку | Нужен установленный `playwright-cli` (`npm install -g @playwright/cli`). Работает там, где он есть |
| img2threejs | Восстановить объект с картинки как код-модель на Three.js | Сокращённая версия без Python-скриптов проверки. Проверки выполняются вручную, это приближение, а не точная копия |

## 3. Как комбинировать

- Сайт: один стиль из раздела 1 (например, design-ibm-engineering-strict) плюс impeccable для итоговой полировки и аудита.
- Калькулятор: design-wise-calculator-forms или design-ibm-engineering-strict для оформления и playwright-cli для проверки формы в браузере.
- Не берите два стиля из раздела 1 одновременно: они конфликтуют по палитре и формам. Исключение: «ориентир на сайт — одни правила, на калькулятор — другие».

## 4. Что не добавлено

Для остальных брендов из набора awesome-design-md (Airbnb, Apple, Binance, BMW M, Bugatti, Cal, Clay, ClickHouse, Cohere и др.) карточки я готовил, но они не сохранены: для вашей задачи они не подходят. Если понадобятся, их можно подготовить заново.

## 5. Если скилл «не виден»

Новые карточки вытесняют предыдущие. Если вы не нажали «Сохранить» вовремя, скилл не появится. Попросите меня подготовить его заново и сохраняйте сразу.
